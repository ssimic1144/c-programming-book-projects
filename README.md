# My solutions for projects in C Programming A Modern Approach 

This repo contains my solutions for programming projects in the book 
C Programming A Modern Approach 2nd ed writen by K N King.

The book's ISBN-10 is : 0393979504

## How do I run examples ? 

You can do it like this with GCC: 

```bash
$ gcc X.c -o X
```

Some chapters make use of `Makefile` to compile solutions to programming projects.

`Makefile` contains all logic required to run the solution. 
You can use `make` to compile those examples:

```bash
$ make Makefile
```

Some examples use C99 syntax.
